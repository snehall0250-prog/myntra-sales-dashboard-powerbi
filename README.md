# 🛍️ Myntra Sales & Customer Analytics Dashboard

Interactive Business Intelligence Dashboard built using Power BI.

## 📌 Project Overview

This dashboard analyzes Myntra sales, customer demographics, product ratings, cities, and purchasing trends using Power BI.

## 🛠️ Tools Used

* Microsoft Excel
* Power BI
* DAX
* Power Query

## 📊 Dashboard KPIs

* 👨 Male Customers
* 👩 Female Customers
* 📍 Number of Cities
* ⭐ Highest Rated Product
* 💰 Total Sales
* 📦 Orders
* 🛒 Categories

## 📈 Dashboard Pages

### Page 1 — Sales Overview

* KPI Cards
* Sales by Category
* Sales by City
* Ratings Distribution
* Gender Distribution

### Page 2 — Customer Analysis

* Customer Ratings
* Top Products
* Top Cities
* Purchase Analysis

### Page 3 — Business Insights

* Revenue Trends
* Top Performing Categories
* Interactive Filters
* Dynamic DAX Measures

## 📊 DAX Measures Included

* Total Sales
* Average Rating
* Total Customers
* Male Customers
* Female Customers
* Number of Cities
* Highest Rated Product

## 🚀 Key Insights

* Identified top-performing cities.
* Compared male vs female customer purchases.
* Analyzed highly-rated products.
* Built reusable DAX measures for KPIs.
